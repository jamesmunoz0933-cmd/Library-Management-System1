📋 Library Rules & Guidelines

Please read and follow the library rules and guidelines when using the Father Borromeo Library.

🔍 SIMPLE STEPS IN FINDING A BOOK IN THE LIBRARY

  1. Scan the QR Code
  2. Search the Database Using the Book Title or Keyword
  3. Take Note of the Record Number and Location
  4. Go to the Shelf
  5. Find the Book Using the Record Number
  6. Borrow or Use the Book

Note: If you wish to borrow the book for circulation, please bring the book to the Library Office for assistance and proper recording.

For room use only: Please follow the library's borrowing procedures and return the book as indicated by the staff.

⚠️ IMPORTANT REMINDERS

  • Books for room use only may be used by retreatants within the designated retreat area, according to library guidelines.
  • Books taken outside the designated area must be properly borrowed and recorded.
  • Please do not return borrowed books directly to the shelves. Give them to the Library Office for proper recording.
  • Please keep the books clean and in good condition.
  • Do not write, underline, highlight, fold, or damage the pages.
  • Please observe the due date and return books promptly.
  • If you need to extend the borrowing period, please ask the Library Office for assistance before the due date.
